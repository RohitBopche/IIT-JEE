|---|---|
| `MTM_JEE_Main_2021.xlsx` | `Tests` + `Questions` tabs for the MTM Google Sheet → "🔄 Sync to MTM" (`scripts/google-sheets-sync.gs`). position 1-based, correct A–D (numerical = value). |

exam_slug `jee-main`, 3600 s. Questions: exam `JEE Main`, source `JEE Main 2021`, is_pyq,
year, topic = chapter, difficulty easy/medium/hard, type standard / assertion_reason /
numerical (tolerance 0), math `$…$` → `\(…\)` with math_format `latex`, explanation opens
`Correct answer: (x)` (house template read by verify_answer_keys.py).
Left out: 3 Bonus/dropped MCQs with no valid key (02-24 E PHY A20, 02-26 M PHY A18, 03-17 E PHY A03).

Upsert (from a machine that can reach Supabase):
```
python3 -m extractor.upsert_mtm --env ../mocktestmitra/.env
```
Figures are uploaded first, then tests (on_conflict=id), then questions (on_conflict=test_id,position).
